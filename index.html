Final Project

Academic Research Agent

A Python multi-agent workflow with optional Ollama planning, OpenAlex retrieval, deterministic ranking, transparent fallback and a three-cycle safety bound.

Eight tests cover planning contracts, model failure, deduplication, ranking, persistence, bounded execution and the command-line workflow. The offline demonstration is reproducible without credentials.
